# Track A options considered (2026-09-29 snapshot)

**Historical.** This is the "how we got here" part of the Google doc "OpenMANET Track A: Field Node POC Status (Sept 29, 2026 snapshot)", moved here on 2026-10-01. It records the options weighed and why each was chosen or rejected as of 2026-09-29. Several "Chosen" rows below were later retired: the mini base carrier, the Sixfab HAT plus GW16151 chain, the GW16170 as the first POC radio, and the Alfa MT7612U adapter (D-003, R-09, R-10). The current selections are in [track-a.md](track-a.md). Do not use this file to decide hardware.

## Carrier board

| Option | Outcome | Why |
|---|---|---|
| Waveshare CM5-IO-WIRELESS-BASE (5.7 x 3.5 in, 7-36 V input, CAN/RS485, M.2) | Replaced on 2026-09-29, then re-selected by D-003 | Bigger than the whole MPU5 chassis; its extras were judged unnecessary once HaLow moved to USB |

## Second HaLow radio

A second HaLow radio per node was requested and shelved. A Morse Micro engineer stated on 2026-08-26 that the Linux driver does not support two HaLow radios on one host, and another advised 2 to 3 m (6 to 10 ft) of separation between co-located radios to avoid adjacent-channel interference. The second link is Wi-Fi on a different band (D-004, R-14, [GHO-39](https://linear.app/ghostnet-labs/issue/GHO-39)).

| Option | Outcome | Why |

| L3Harris 12041-2400-0X handheld battery | Parked, then retired for Track B (R-01) | 10.8 V nominal, 7.0 Ah, 4.0 A limit, unknown contact interface |

## RTC battery

The rechargeable ML1220 is discontinued (Panasonic end of life, August 2022), so the choice is a non-rechargeable CR1220 with RTC charging left off.

## Software notes from the snapshot

- Mesh: 802.11s with forwarding off so batman-adv routes; start on US channel 28 (8 MHz at 916 MHz).
- openmanetd (beta) gives automatic addressing, gateway selection, gpsd and CoT publishing.
- HaLow power is adjustable with `iw wlan0 set txpower fixed` (units of 0.01 dBm); persistence needs a small script edit.
- Fallbacks: install OpenMANET's feed on stock OpenWrt, or build openmanetd alone. The community Pi 5 image is unsuitable because its driver predates M20 support.
- The CM5 board target was later built as `ekh-bcm2712` (D-021).

## Size concepts considered

Estimates only, never dry-fitted.

| Concept | Size (W x H x D) | Notes |
|---|---|---|
| MPU5 target chassis | 2.6 x 4.6 x 1.5 in | 18 cubic in (31 with its battery) |
| Flat slab | 7.7 x 6.2 x 1.4 in | Huge footprint; dropped |
| Portrait, two layers, 3-cell UPS | about 3.8 x 5.0 x 2.2 in (43 cubic in) | Chosen for the mini-base concept |
| Portrait, two layers, 4-cell X1206 | about 3.6 x 5.5 x 2.4 in (48 cubic in) | No spare pocket for the GPS |
| L3Harris battery at the bottom | about 3.4 x 8.2 x 1.9 in (53 cubic in) | MPU5-like shape |
| L3Harris battery on the back | about 3.4 x 4.6 x 3.0 in (47 cubic in) | Familiar footprint but thick |

The dev-kit boards alone came to about 22 cubic inches before spacing and walls. The conclusion still holds: reaching MPU5 thickness needs a custom carrier with the E-key socket built in, which is Track B.
